# Security

Please report security issues privately to hello@tokconnect.com. Do not include live credentials in public issues.

This package is a local stdio connector, not a standalone TikTok backend. Keep your TokConnect API key in a private client configuration or environment. It is sent only to the fixed HTTPS TokConnect MCP endpoint; redirects are rejected. The package contains no TikTok session cookies, proxy credentials or account databases.

The MIT license applies only to this connector. It does not grant access to the hosted service without authentication, or permission to bypass its limits.
